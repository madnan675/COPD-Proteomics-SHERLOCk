# COPD-Proteomics-SHERLOCk
Analysis of clinical and Olink proteomics data from COPD and control cohorts, comparing eosinophilic and non-eosinophilic COPD (blood eosinophils ≥0.3 × 10⁹/L). Includes baseline characteristics, differential protein expression, pathway enrichment, data visualization, and protein-protein interaction network analysis to identify hub proteins.
